# CLI-эксперименты этапа 1

Складывайте сюда исполняемые скрипты каждого эксперимента, например:

- `01-create-topics.sh` — создание топиков с разными RF и числом партиций
- `02-keys-vs-nokeys.sh` — сравнение распределения по партициям
- `03-leader-failover.sh` — остановка лидера и наблюдение переизбрания
- `04-retention.sh` — эксперимент с retention.ms
- `05-compaction.sh` — эксперимент с cleanup.policy=compact

Каждый скрипт должен быть самодостаточным и воспроизводимым:
создать → выполнить → показать результат → прибрать за собой.
